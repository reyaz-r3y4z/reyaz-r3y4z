How it works

01
Tokenization — GPT-2 BPE via tiktoken converts raw text into a 50,257-token vocabulary stream.
02
Embeddings — Token + position embeddings combine into 768-dim vectors feeding the transformer stack.
03
Attention — 12 causal self-attention heads let each token learn from everything before it, never after.
04
Training — AdamW, cosine LR schedule, gradient accumulation to fit a 64-sequence effective batch in 8GB VRAM.
05
Two runs — 3,000-step run reached loss 3.11; a 48-hour continuation extended training to 13,700 total steps.
